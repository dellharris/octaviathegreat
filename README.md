# Octavia the Great

Artist materials for Octavia the Great, prepared by IDU House.

| File | What it is |
|---|---|
| `artist.md` | Artist profile: bio, links, catalog, release model, open questions |
| `one-sheet.html` | The artist one sheet (US Letter, prints as one page) with a Contact button to IDU House |
| `metrics.json` | Numbers shown in the At a glance section (Threads impressions and followers). Empty values stay hidden |
| `assets/` | Images used by the one sheet |
