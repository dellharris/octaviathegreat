# Octavia the Great

Artist materials for Octavia the Great, prepared by IDU House.

| File | What it is |
|---|---|
| `artist.md` | Artist profile: bio, links, catalog, release model, open questions |
| `one-sheet.html` | IDU House invitation for Octavia: how we work together, the first 90 days, and a built in calendar to book the next meeting. Page one prints as a US Letter sheet (File, Print, Save as PDF, background graphics on, margins none). The calendar shows on the web version only |
| `busy.json` | Times to block on the calendar. Add `{"start": "ISO time", "end": "ISO time"}` entries to hide slots |
| `assets/` | Images used by the one sheet |
